# Fit a Binomial distribution to data

The fit distribution will inherit the same `size` parameter as the
`Binomial` object passed.

## Usage

``` r
# S3 method for class 'Binomial'
fit_mle(d, x, ...)
```

## Arguments

- d:

  A `Binomial` object.

- x:

  A vector of zeroes and ones.

- ...:

  Unused.

## Value

a `Binomial` object
