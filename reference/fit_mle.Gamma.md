# Fit a Gamma distribution to data

Fit a Gamma distribution to data

## Usage

``` r
# S3 method for class 'Gamma'
fit_mle(d, x, ...)
```

## Arguments

- d:

  A `Gamma` object created by a call to
  [`Gamma()`](https://zeileis.github.io/distributions3/reference/Gamma.md).

- x:

  A vector to fit the Gamma distribution to.

- ...:

  Unused.

## Value

a `Gamma` object
