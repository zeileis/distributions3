# Fit a Log Normal distribution to data

Fit a Log Normal distribution to data

## Usage

``` r
# S3 method for class 'LogNormal'
fit_mle(d, x, ...)
```

## Arguments

- d:

  A `LogNormal` object created by a call to
  [`LogNormal()`](https://zeileis.github.io/distributions3/dev/reference/LogNormal.md).

- x:

  A vector of data.

- ...:

  Unused.

## Value

A `LogNormal` object.
