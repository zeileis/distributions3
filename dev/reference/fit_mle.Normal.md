# Fit a Normal distribution to data

Fit a Normal distribution to data

## Usage

``` r
# S3 method for class 'Normal'
fit_mle(d, x, ...)
```

## Arguments

- d:

  A `Normal` object created by a call to
  [`Normal()`](https://zeileis.github.io/distributions3/dev/reference/Normal.md).

- x:

  A vector of data.

- ...:

  Unused.

## Value

A `Normal` object.
